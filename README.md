# Briefly

Čítačka správ pre Android. Vlastné RSS zdroje, čítací režim bez otvárania
prehliadača, offline režim a zhrnutia článkov priamo v telefóne.

Toto je verejné úložisko pre distribúciu — zdrojový kód je inde.

## Stiahnutie

| | |
|---|---|
| Aplikácia | [briefly-latest.apk](https://github.com/frodo21/briefly/releases/download/latest/briefly-latest.apk) |
| AI model | [gemma3-1b-it-int4.task](https://github.com/frodo21/briefly/releases/download/model/gemma3-1b-it-int4.task) |
| Zásady ochrany súkromia | [privacy.html](https://frodo21.github.io/briefly/privacy.html) |

APK sa aktualizuje pri každom builde. Model si aplikácia stiahne sama, keď
o to požiadaš v nastaveniach — sťahovať ho ručne netreba.

## AI model

Model je [Gemma 3 1B](https://ai.google.dev/gemma) od Google, prevedený do
formátu LiteRT komunitou LiteRT. Beží celý v telefóne, nič neodchádza na
server. Platia pre neho [podmienky použitia Gemma](https://ai.google.dev/gemma/terms)
vrátane [zásad zakázaného použitia](https://ai.google.dev/gemma/prohibited_use_policy).
Stiahnutím súboru s nimi súhlasíš.
